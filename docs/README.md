# 文档索引

本目录存放项目的长期文档。代码和构建说明见仓库根目录的 [README](../README.md)。

| 文档 | 内容 | 什么时候看 |
| --- | --- | --- |
| [版本说明](版本说明.md) | 版本总览表，以及每个版本的新增、修复、验证与遗留问题 | 想知道某个版本改了什么、为什么这么改 |
| [审查报告](审查报告.md) | 第 1–9 轮代码审查记录，含发现、处置、误报澄清与测试结果 | 想追溯某个问题的根因和修复过程 |

## 维护约定

- **发版**：改代码时同步更新 `版本说明.md`，先在总览表加一行，再补对应版本的详情小节；表内版本按从新到旧排列。
- **审查**：每轮审查在 `审查报告.md` 末尾追加一节，标题格式为 `## 第 N 轮 · 主题`，并同步补目录。原文不改写，历史结论按当时情况保留。
- **提交信息**：遵循 `类型(范围): 描述` 格式（feat/fix/docs/refactor 等）。
